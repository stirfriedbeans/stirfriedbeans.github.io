Break the Cipher

Muba just tucked the team's final secret prize beneath a pile of leaves — but he's pretty sure someone's been listening in. Rather than risk saying the location out loud, he decides to send his colleagues a cipher instead.

A cipher is created by transforming letters into numbers consisting of one or more digits. No code starts with another code. For instance, if the letter A is transformed into 12, the letter B can be transformed into 2 (because 12 does not start with 2). In such a case, the letter C can be transformed into 11 (because both 12 and 2 do not start with 11), but not into 21 (because 2 has been already used for B) or into 121 (because 12 has already been used for A).

Task

Separate the digits below, by clicking on the empty spaces, so that each sequence, enclosed by brackets, is the code of a letter in the word LEAVES.

(Remember to press Save when you have finished.)
